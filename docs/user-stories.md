# User Stories

## User Stories 1

As a university student, I want to receive an employment-related prediction based on my information, so that I can better understand the outcome estimated by the model.

### Acceptance criteria
1. Given that all mandatory fields contain valid information, when the student submits the information, the system shall display a prediction.
2. The displayed prediction shall state that the result is an estimate and not a guarantee of employment.

## User Stories 2

As a university student, I want to review my skills analysis, so that I can identify areas for further development.

### Acceptance criteria
1. Given that the required skill information is available, when the student opens the results view, the system shall display the skills analysis.
2. The system shall identify skills that do not meet documented assessment criteria.

## User Stories 3

As an authorised university staff member, I want to review permitted student employability information, so that I can identify common career-development needs.

### Acceptance criteria
1. Given that the staff member has the required permission, when they request permitted student information, the system shall allow access.
2. Given that a user lacks the required permission, when they attempt to access restricted student records, the system shall deny access.
