# Selected Specialized Technology: Supervised Machine Learning

Supervised machine learning is chosen because it learns patterns from labeled examples, and can predict a result. It will be investigated in this project for prediction of student employability from the available student-related information. The effectiveness of the approach will depend on the availability of a data set for which a well-defined target outcome exists.

# Three Credible Sources

1. Machine Learning Fundamentals

Google. (n.d.). Machine Learning Crash Course Book. Developers Google: https://developers.google.com/machine-learning/crash-course/

Relevance: This source covers supervised learning, classification and model evaluation. It will reinforce the understanding of machine learning learning from data and prediction.

2. Random Forest Algorithm

Breiman, L. (2001). Random forests. Machine Learning, 45, 5–32. https://doi.org/10.1023/A:1010933404324

Random Forest: This research paper introduces the Random Forest algorithm that is a combination of various decision trees that make predictions. Can be used in investigating Random Forest as a candidate model to predict employability of students.

3. Tools for Decision Tree and Machine learning

scikit-learn developers. (n.d.). Decision Trees. scikit-learn documentation. https://scikit-learn.org/stable/modules/tree.html

Target Audience: This documentation is written for people interested in relevance, particularly those looking into classification issues. It also offers hands-on examples of how to apply machine learning algorithms using Python's scikit-learn library.
